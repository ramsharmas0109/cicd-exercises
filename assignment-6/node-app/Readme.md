# Node.js HTTP API

A simple Node.js HTTP application that runs on port `3000`.

## Install Dependencies

```bash
npm ci
```

## Run Locally

```bash
npm start
```

Verify:

```bash
curl localhost:3000
```

### Expected

```text
Hello from Node!
```

## Run Tests

```bash
npm test
```

## Validate

```bash
npm run check
```
